## A note on the published version

This repository contains the **pipeline only**. The database project it was
built for is not included: it was a production analytics schema, and its
contents are commercial rather than reusable engineering.

`demo/DemoDb/` is a purpose-built stand-in so the pipeline runs end to end.

All hostnames, database names, roles, approver lists, and credential
identifiers are placeholders.
