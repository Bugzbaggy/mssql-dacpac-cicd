# Security Policy

## Reporting a vulnerability

Please **do not open a public issue** for a security problem. Use GitHub's
[private vulnerability reporting](https://github.com/Bugzbaggy/mssql-dacpac-cicd/security/advisories/new)
instead.

## Scope note for contributors

This project automates database administration. Treat every example
connection string, hostname, and account name as a placeholder, and never
paste real ones into issues, pull requests, or test fixtures — including in
logs and stack traces attached to bug reports.

Values such as `listener.example.com`, `listener.region1.example.com`,
`AppDb_Analytics`, `policygate.example.com`, `approver1`, and `192.0.2.x`
addresses are deliberately fictional. Keep them that way.
